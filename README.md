# XBOX Half Life 2 Material files.

XBOX Half Life 2 Material files, with XTF files converted to VTF 7.4

Not all materials were converted properly or well. This was automated after all.

If there is a specific texture you want or need to be re-converted, please reach out to me! Open an #issue and I'll take a look when I can.
